# Simple Login Authentication System 🔐

## Project Description
Simple Login Authentication System is a C++ based project that verifies user credentials and provides access only when the entered username and password match the stored credentials.

This project demonstrates the basic concept of user authentication using conditional statements in C++.

## Features
- User login verification
- Username and password authentication
- Success and error messages
- Simple and user-friendly console interface

## Technologies Used
- Programming Language: C++
- Concepts Used:
  - Strings
  - Variables
  - Input and Output
  - If-Else Statements
  - Conditional Operators

## How to Run the Project

1. Clone or download this repository.
2. Open the `.cpp` file in a C++ compiler.
3. Compile the program.
4. Run the executable file.
